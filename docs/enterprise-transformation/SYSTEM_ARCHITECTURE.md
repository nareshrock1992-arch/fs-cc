# System Architecture (as found, cycle 1)

```
Browser: Admin portal (frontend/, React)     Browser: Agent desktop (agent-desktop/, React + sip.js)
   │ REST /api/* (JWT admin|supervisor)          │ REST /api/agent-desk/* (JWT agent)      │ SIP over WSS :7443
   │ socket.io (supervisor:authenticate)         │ socket.io (agent:authenticate)          ▼
   └──────────────► backend/ (Express :4000) ◄───┘                                  FreeSWITCH (sofia internal)
                     │  PostgreSQL (pool.js, migrations/)                               ▲
                     │  eslService.js ── ESL :8021 ── mod_callcenter, channels ─────────┘
                     │  socketService.js: ccEvents → rooms (subscribers, agent:<id>, supervisors)
```

## Auth model
| Client | Token | Accepted by |
|---|---|---|
| admin / supervisor (`users` table, bcrypt password) | JWT `{role, permissions}` | `/api/*` (`requireAuth`; admin-only routes `requireAdmin`; `requirePermission(view_reports | change_agent_state | manage_break_codes | view_caller_id)`) |
| agent (`agents.pin_hash`, bcrypt PIN) | JWT `{role:'agent', agentId}` | `/api/agent-desk/*` only (`requireAgentAuth`) — since SEC-1 rejected elsewhere |

## Live events
ESL events normalised in `eslService` → `ccEvents` → socket rooms. Since SEC-3: `subscribers` (any authenticated socket) receives call/agent events; `agent:<id>` targeted; `supervisors` gets pre-queue monitor. Unauthenticated sockets: `esl:status` only.

## Data
Tables: agents, agent_tiers, queues, calls, agent_state_log, agent_sessions, agent_state_events, break_codes, audit_log, users. Migrations 001–011 run at startup (`migrationRunner.js`). No tenant scoping.

## Telephony
Queue routing = mod_callcenter (strategies available natively: ring-all, longest-idle-agent, round-robin, top-down, agent-with-least-talk-time, agent-with-fewest-calls, sequentially-by-agent-order, random, ring-progressively). Queue XML generated by `utils/queueXml.js`. Browser phone = sip.js engine in `agent-desktop/src/features/softphone/engine`; transfer = SIP REFER (blind) and REFER/Replaces (consult).
